# K'ab T'aan · sitio informativo

Sitio web del proyecto **K'ab T'aan** (Infomatrix 2026, proyecto 41085): explicación del proyecto, avatar 3D,
«Pruébalo» en el navegador y la bitácora en PDF.

Publicado en <https://tonyluno9.github.io/inclusion-digital/>.

- `sitio/`: lo que se publica (HTML, CSS y JavaScript, sin compilar nada).
- `.github/workflows/pages.yml`: lo publica en GitHub Pages en cada cambio a `main`.

El código de la app de escritorio, el entrenamiento y el avatar en Blender está en un repositorio privado.
